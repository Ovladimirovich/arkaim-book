# Правила именования

- `snake_case` для Python-файлов, `.json` только для данных
- `.md` только для документации, `.yaml` только для конфигурации
- `UPPER_CASE` для корневых папок проекта (ARKAIM-WEB, ARKAIM-MOBILE)
- `snake_case` для подпапок
- `PascalCase` для классов, `camelCase` для переменных/функций в TS
- Магические числа и строки выносятся в константы

## Язык
- Все комментарии, логи, интерфейс, промпты — на русском языке
- Имена файлов/папок — на английском
- Технические метаданные (JSON поля, system prompts) — на русском
