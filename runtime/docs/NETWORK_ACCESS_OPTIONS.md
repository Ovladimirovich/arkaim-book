# Варианты публикации системы в интернет

## Зачем это нужно
Чтобы единомышленники могли получить доступ к книге «Наследие Аркаима» через браузер или API из любой точки мира. Без этого система работает только на локальном ПК (`127.0.0.1`).

## Общий принцип
Все варианты работают одинаково: внешний адрес (домен или ссылка) → защищённый канал → ваш ПК → `localhost:8080` (Gateway). Ни один из вариантов **не требует открытия портов на роутере**.

Система уже готова: Gateway слушает `127.0.0.1:8080`, а не `0.0.0.0`, то есть снаружи доступа нет — только через туннель.

---

## Вариант 1: Cloudflare Tunnel (рекомендуемый)

Плюсы: HTTPS, быстрый, постоянный адрес, скрывает IP, бесплатно (кроме домена).
Минусы: нужен свой домен и аккаунт Cloudflare.

### Что нужно
1. **Домен** — купить у регистратора (Reg.ru, Nic.ru, любой) за ~200-500 руб/год
2. **Аккаунт Cloudflare** — зарегистрироваться на cloudflare.com (бесплатно)
3. **cloudflared** — установить на Windows (инструкция ниже)

### Пошагово
1. Добавить домен в панель Cloudflare → получить NS-сервера
2. Поменять NS-сервера у регистратора на те, что дал Cloudflare
3. В панели Cloudflare → Zero Trust → Tunnels → создать туннель
4. Указать маршрут: `ваш-домен.ru → http://localhost:8080`
5. На ПК запустить:
```powershell
cloudflared tunnel run имя-туннеля
```
6. Для постоянной работы — зарегистрировать как Windows-сервис через NSSM (уже установлен).

**Результат:** `https://arkaim.ваш-домен.ru` → ваш Gateway

## Вариант 2: Tailscale Funnel (рекомендуется если уже используете Tailscale)

Плюсы: не нужен домен, HTTPS бесплатно, просто.
Минусы: нужен Tailscale (VPN-подобная сеть) у вас и у участников.

### Что нужно
1. **Аккаунт Tailscale** — зарегистрироваться на tailscale.com (бесплатно для личного использования)
2. **Клиент Tailscale** — установить на Windows

### Пошагово
1. Установить Tailscale и войти в аккаунт
2. Запустить Funnel:
```powershell
tailscale funnel --bg 8080
```
3. Получить адрес: `https://имя-пк.ts.net`

**Результат:** `https://имя-пк.ts.net` → ваш Gateway
**Ограничение:** участники тоже должны быть в вашей Tailscale-сети (или использовать Funnel — `--https 8080` делает доступ публичным).

Документация: https://tailscale.com/kb/1223/funnel/

## Вариант 3: ngrok (самый быстрый для теста)

Плюсы: не нужен домен, 5 секунд на запуск.
Минусы: URL меняется при каждом запуске (кроме платного тарифа), ограничение 40 соединений/мин в бесплатной версии.

### Что нужно
1. **Аккаунт ngrok** — зарегистрироваться на ngrok.com (бесплатно)
2. **ngrok** — скачать и установить

### Пошагово
```powershell
ngrok config add-authtoken ваш-токен
ngrok http 8080
```
Получить ссылку в консоли: `https://что-то.ngrok-free.app`

**Результат:** временная HTTPS-ссылка → ваш Gateway

---

## Вариант 4: localhost.run (без установки, через SSH)

Плюсы: ничего не нужно устанавливать, нет регистрации.
Минусы: только SSH-доступ, ссылка меняется.

```powershell
ssh -R 80:localhost:8080 nokey@localhost.run
```

**Результат:** `https://что-то.lhrtunnel.link` → ваш Gateway

---

## Сравнение

| Вариант | Домен | HTTPS | Постоянный адрес | Установка | Бесплатно |
|---|---|---|---|---|---|
| Cloudflare Tunnel | Да | Да | Да | cloudflared + NSSM | Да |
| Tailscale Funnel | Нет | Да | Да | Tailscale клиент | Да |
| ngrok | Нет | Да | Нет (бесплатно) | ngrok | Да (с ограничениями) |
| localhost.run | Нет | Да | Нет | SSH | Да |

## Рекомендация
Начать с **ngrok** для теста (за 1 минуту), затем перейти на **Cloudflare Tunnel** для постоянного доступа, когда появится домен.
