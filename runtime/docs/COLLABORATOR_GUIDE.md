# Руководство для единомышленника

## Как получить доступ

1. Администратор выдаст вам ссылку: `https://arkaim.ваш-домен.ru`
2. Откройте ссылку в браузере, нажмите **«Войти через Telegram»** или **«Войти через Google»**
3. После входа вы попадёте на дашборд

## Что можно делать

- **Читатель (reader)** — задавать вопросы книге, просматривать черновики, смотреть аналитику
- **Редактор (editor)** — всё как у читателя + загружать документы, генерировать контент, одобрять черновики
- **Администратор (admin)** — полный доступ, включая X-Ray диагностику и управление пользователями

## Ваш API-ключ

Для доступа через API-клиенты (curl, код):

1. Откройте дашборд → нажмите **«API-ключ»** → **«Сгенерировать новый»**
2. Скопируйте ключ (показывается один раз)
3. Используйте в заголовке:

```bash
curl https://arkaim.ваш-домен.ru/book/ask \
  -H "Authorization: Bearer ваш_ключ" \
  -H "Content-Type: application/json" \
  -d '{"question":"О чём эта книга?"}'
```

## Часто задаваемые вопросы

**Я потерял API-ключ, что делать?**
Сгенерируйте новый на дашборде. Старый ключ автоматически станет недействительным.

**Куда писать, если нашёл баг?**
Напишите администратору в Telegram.

**Могу ли я пригласить других?**
Да — администратор может выдать доступ новым участникам.
