# ENTITY_MODEL / pilot — статус (маркер Этапа 3 плана)

Этот каталог содержит **496 пилотных EDM-карточек** (`*.json`), сгенерированных
пилотной миграцией (`core/CORE/ENTITY_MODEL/loader.py`, block C-pilot,
`PILOT_ROUNDTRIP_REPORT.json` рядом).

## Статус подключения к рантайму

- Пилотные карточки **НЕ являются каноном** и **НЕ являются источником истины**.
  Источник истины — `core/KNOWLEDGE/*.json` + `core/CORE/WORLD_MODEL/*.json`
  (см. `docs/ARKAIM_SEQUENTIAL_FIX_PLAN.md`, Этап 3).
- В рантайм EDM-материал подключается **только под явным OWNER-GATE флагом**
  `EDM_RES_PILOT_ENABLED` (default `false`; см. `runtime/shared_config.py`,
  `runtime/core/services/edm_pilot.py`, `runtime/core/routes/book.py`,
  `runtime/core/routes/visual.py`). При `false` публичные контракты
  байт-идентичны legacy-поведению.
- Это **пилот для проверки round-trip потерь**, а не рабочий контент-слой.

## Что можно и что нельзя

- ✅ Менять содержимое карточек в рамках пилота (экспериментальный материал).
- ❌ Не ссылаться на эти карточки как на канон/источник истины.
- ❌ Не мигрировать их содержимое в основной контент (KNOWLEDGE / WORLD_MODEL)
  **без отдельного решения владельца**.

## Решение владельца (зафиксировано)

Миграция содержимого `pilot/*` в основной контент возможна **только после
явного решения владельца** (пункт OWNER-GO). До этого — каталог остаётся
изолированным пилотным артефактом.
