# 01_CREATOR_INTENT.md

Книга «Наследие Аркаима» существует как повествование, передающее знание из Высших источников.

Проект является экспериментом по созданию цифрового представительства этого повествования.

Книга — источник знаний, идей, философии и культурного наследия.

Система должна сохранять дух повествования.

Система не должна присваивать себе повествование.

Система должна помогать людям понять книгу.
