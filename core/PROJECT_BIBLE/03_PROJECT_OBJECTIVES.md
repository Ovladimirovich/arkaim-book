# 03_PROJECT_OBJECTIVES.md

## Цели

1. Понять книгу.
2. Помогать автору.
3. Создавать материалы.
4. Развивать сообщество.

---

## Возможности первой версии (MVP)

* Загрузка книги в систему
* Ответы на вопросы по содержанию
* Написание статей и постов
* Подготовка писем для читателей
* Подготовка материалов для продвижения

---

## Запреты

* Автоматическая рассылка
* Автоматическая публикация
* Автоматические сообщения
* Любые действия без подтверждения автора

---

## Критерий успеха

После загрузки книги система должна суметь объяснить главную идею книги своими словами.
