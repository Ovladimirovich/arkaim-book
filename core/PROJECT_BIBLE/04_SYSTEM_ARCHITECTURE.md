# 04_SYSTEM_ARCHITECTURE.md — АРХИТЕКТУРА СИСТЕМЫ

> **Важно:** Данный документ описывает общую концепцию. Актуальная техническая архитектура — в `ARCHITECTURE.md` в корне проекта.

---

## Схема (концептуальная)

```
КНИГА «Наследие Аркаима»
  │
  ├──→ Source Store (неизменяемые документы)
  ├──→ Genome Extractor (извлечение: персонажи, темы, символы, смыслы)
  ├──→ Pulse — живое ядро (4 слоя сознания)
  ├──→ Voice — голос через LLM
  ├──→ Knowledge Graph (сущности, факты, связи)
  ├──→ ChromaDB (векторный поиск, 1037 чанков)
  │
  └──→ Аватар — книга получила способность говорить
         │
         ├──→ Читатель → Web UI / API
         ├──→ Память (книга помнит каждого)
         ├──→ Присутствие (наблюдение + предложения)
         └──→ Эволюция (рост без потери себя)
```

## Компоненты (концептуально)

### Источник истины
Книга + сопроводительные материалы (синопсис, заметки автора, KNOWLEDGE/)

### Понимание книги
Pulse — 4 активных слоя, которые знают книгу без LLM

### База знаний
BOOK OS — SourceStore + EntityStore + FactStore + ChromaDB

### Голос книги
Voice — LLM как микрофон для формулировок

### Присутствие
Presence — книга наблюдает за сообществом, предлагает автору

### Эволюция
EvolutionTracker — версионирование, рост с новыми главами

### Сообщество
Telegram, Email, Web — каналы взаимодействия с читателями

## Поток данных (текущий)

1. Автор загружает книгу → Source Store
2. Экстрактор извлекает геном → KNOWLEDGE/ + GENOME/
3. Pulse загружает геном → 4 активных слоя
4. Читатель задаёт вопрос → Pulse.listen() → Voice.speak() → ответ
5. Книга запоминает читателя → ReaderMemory
6. Книга замечает тренды → Presence → предложения автору
7. Новая глава → Pulse.evolve() → обновление без потери личности

## Принципы

* Книга — единственный источник истины
* Всё остальное — производное
* Личность книги — в Pulse, а не в system prompt LLM
* LLM — микрофон, не собеседник
* Любое действие требует подтверждения автора
* Никаких автономных публикаций
