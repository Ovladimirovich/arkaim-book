# Наследие Аркаима — Полный документ возможностей интерфейса

## Дата: 20 июля 2026
## Версия: 1.0.0

---

## Обзор

«Наследие Аркаима» — цифровое сознание книги. Интерфейс включает **38 страниц** с полным функционалом для чтения, исследования, создания контента и управления миром книги.

---

## Навигация

Интерфейс разделён на 5 групп в боковой панели:

### 1. Книга (10 страниц)

| Страница | Путь | Описание |
|----------|------|----------|
| Задать вопрос | /ask | Минималистичный ввод вопроса, популярные вопросы, streaming |

## Детальное описание страниц

### 1. Задать вопрос (/ask)

**Назначение:** Быстрый доступ к знаниям книги.

**Функции:**
- Минималистичный ввод вопроса
- Популярные вопросы (быстрые ссылки)
- Streaming-ответ ( SSE)
- История вопросов
- Сохранение в профиле

**Интерфейс:**
- Поле ввода с автодополнением
- Кнопка «Отправить»
- Область ответа с markdown-рендерингом
- Индикатор загрузки

---

### 2. Чат с книгой (/book)

**Назначение:** Интерактивный диалог с миром книги.

**Функции:**
- Streaming-ответы (SSE)
- Управление сессиями (создание, переключение, удаление)
- Sidebar с темами и профилем
- Статистика использования
- Контекст предыдущих сообщений

**Интерфейс:**
- Лента сообщений (user/assistant)
- Поле ввода с кнопками форматирования
- Боковая панель с темами
- Индикатор набора текста

---

### 3. Чтение (/reading)

**Назначение:** Чтение текста книги.

**Функции:**

- Навигация по главам
- Прогресс чтения
- Закладки

**Интерфейс:**
- Текстовый блок с настройками
- Боковая панель с оглавлением
- Полоса прогресса
- Кнопки навигации

---

### 4. Сценарий (/screenplay)

**Функции:**
- Оглавление сцен

**Интерфейс:**
- Форматированный текст сценария

## Авторизация

### Способы входа

| Способ | Описание |
|--------|----------|
| Telegram бот | `/login` → токен → ссылка → JWT + cookie |
| Email | `/register` → форма → JWT + cookie |
| Dev-режим | Кнопка «Войти как разработчик» → dev-login API → JWT + cookie |

### Cookie

- Имя: `arkaim_session`
- Тип: HttpOnly
- SameSite: Lax
