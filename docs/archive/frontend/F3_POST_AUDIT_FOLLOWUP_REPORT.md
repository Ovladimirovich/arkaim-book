## 2. PA-1 — регистрация F3-тестов в штатном раннере (HIGH) — CLOSED

**Диагноз пост-аудита:** `scripts/run-tests.mjs` содержит жёсткий список из 10 файлов; `temporal.test.ts` и `provenance-badge.test.ts` в него не попали — «67/67» не включало их.

**Корневая причина (исследовано):** discovery этого раннера и есть явный список TESTS — авто-поиска файлов в нём нет. Это осознанная конструкция среды (sandbox блокирует spawn → настоящий vitest здесь не стартует, см. «startup Error: spawn EPERM» при попытке `npm test`; CI-джоба frontend-v2-test гоняет настоящий vitest с default-glob `tests/**` и находит оба файла сам). Проблема была не в «механизме поиска», а в том, что при добавлении двух новых файлов их забыли вписать в список.

**Fix:** две строки в `scripts/run-tests.mjs` (TESTS-массив) + поясняющий комментарий.

**Доказательство (штатный прогон, реальный вывод):**
