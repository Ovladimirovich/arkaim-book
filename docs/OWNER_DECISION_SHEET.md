## G1. Внешние источники по claim'ам `ARCHAEOLOGY.json` — реестр составлен, ждём решения по каждому claim'у

**Где зафиксировано:** `docs/WORLD_MODEL_PROVENANCE_AUDIT_2026-10-20.md:33,76`

**Суть.** `core/KNOWLEDGE/ARCHAEOLOGY.json` содержит утверждения об археологии, часть которых
не имеет указанного источника. Для каждого claim нужно либо указать внешний источник, либо
явно пометить `source: UNKNOWN`.

**Что сделано (2026-10-22):**
- Составлен **реестр неподтверждённых claim'ов** с индивидуальным уровнем доказательности,
  происхождением и пробелами: `docs/G1_UNCONFIRMED_CLAIMS_REGISTER_2026-10-22.md`.
  Шкала: E0 — источника нет; E1 — общеизвестно; E2 — источник найден, не проверен;
  E3 — подтверждено. Сейчас **36 claim'ов на уровне E0**, 0 на E1–E3.
- Подобраны **кандидаты на источники** (автор, название, год, журнал/издательство) для
  каждого сайта: `docs/G1_ARCHAEOLOGY_SOURCES_2026-10-22.md`. Это рекомендация, а не внесённый
  источник — ни одна фиктивная ссылка не создана.
- Отдельно исследован термин «Каргонодская культура» (раздел 6 реестра): имени нет в реальной
  археологии → запись удалена по решению владельца.
- Зафиксировано 8 **системных пробелов** (П1–П8), главные: нет поля `source` ни у одного
  claim'а; `facts_provenance` стоит на блоке, а не на факте; зеркала содержат самоссылку
  и `confidence: 1.0` при пустом `content`.

**Ни один claim не переведён в CANON, ни один источник не выдуман, ни одна запись
не изменена без решения владельца.**

| Вариант | Что получится | Последствия |
|---|---|---|
| **1. Указать источники** | Каждый claim получает `source` (название работы, автор, год) | Нужны ваши ссылки; я не могу додумывать библиографию |
| **2. Пометить `UNKNOWN`** | Прозрачность: система знает, что источник неизвестен | Ответы честно скажут «по внешним данным без указанного источника» |
| **3. Оставить как есть** | Факт остаётся, но не прослеживается | Расхождение реестра и данных сохранится |

**Что сделаю после ответа:** внесу `source` (или `UNKNOWN`) в `ARCHAEOLOGY.json` по вашему
указанию, синхронизирую реестр классификации, добавлю тест на заполненность поля.
