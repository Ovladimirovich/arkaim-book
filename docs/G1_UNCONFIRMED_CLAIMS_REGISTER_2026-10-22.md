## 5. Системные пробелы (не зависят от отдельного claim'а)

| # | Пробел | Где | Следствие |
|---|---|---|---|
| **П1** | Нет поля `source` у claim'ов | `core/KNOWLEDGE/ARCHAEOLOGY.json` | невозможно проследить, откуда взят факт; автоматическая проверка заполненности невозможна |
| **П2** | `facts_provenance: EXTERNAL_SOURCE` присвоен **всему блоку** facts | там же, на уровне сайта | нет индивидуального статуса доказательности claim'а — то, что G12 Q1 требует сохранить |
| **П3** | `_provenance_metadata` есть только на уровне файла, не на уровне записей | там же | claim не может нести `pages`/`doi`/`source_level` персонально |
| **П4** | `significance` смешивает факт и оценку в одном поле | там же | «Аркаим — единственный город-центр» — оценочное суждение подписано как внешний источник |
| **П5** | Зеркала содержат самоссылку `source: ARCHAEOLOGY.json.sites[N]` и `confidence: 1.0` при пустом `content` | `ARCHAEOLOGY_DEEP.json`, `GEOGRAPHY.json`, `TECHNOLOGY.json` | зеркало выглядит подтверждённым, хотя данных в нём нет |
| **П6** | `provenance_notes` у записей World Model = «Картографические данные» | `core/CORE/WORLD_MODEL/GEOGRAPHY.json` | для археологических записей подпись неверна |
| **П7** | Ни один из объектов не встречается в книге | `core/SOURCE_OF_TRUTH/BOOK/КНИГА.md` — 0 вхождений | книжное обогащение по ним **невозможно**; отсутствие в книге ≠ опровержение |
| **П8** | `unsolved` (3 у Аркаима) — открытые вопросы хранятся рядом с фактами | `core/KNOWLEDGE/ARCHAEOLOGY.json` | формат не различает «неизвестно» и «не утверждается» |
