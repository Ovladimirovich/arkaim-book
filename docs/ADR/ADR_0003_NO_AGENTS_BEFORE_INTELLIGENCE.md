# ADR-0003: Нет агентов до появления Intelligence

## Статус
Принято

## Контекст
Project использует термины "агенты", "оркестрация", "LangGraph" из мира LLM-архитектур.

## Решение
На этапах Foundation, Reader, Understanding, Genome агенты не используются.

Агенты появляются только после того, как система достигнет BOOK INTELLIGENCE — способности самостоятельно отвечать на вопросы о книге.

## Последствия
- На ранних спринтах архитектура максимально простая (один процесс, sync/async)
- Отсутствует overhead на оркестрацию, маршрутизацию, state management
- Код предсказуем и легко тестируется
- При необходимости агентов можно добавить позже без переделки ядра
