# ADR-0004: Single Book First

## Статус
Принято

## Контекст
Первая версия системы создаётся для одной книги «Наследие Аркаима».

## Решение
Масштабирование на несколько книг откладывается до версии 2.0.

Архитектура проектируется так, чтобы добавление второй книги не требовало переделки核心,
но не реализуется до подтверждённой необходимости.

## Последствия
- Нет абстракций "library", "books collection", "multi-tenancy"
- Все пути, идентификаторы и конфигурация заточены под одну книгу
- BOOK_ID = "nasledie-arkaima" — единственный в системе
- При добавлении книги v2 появляется новый слой абстракции
