# ADR-0002: Книга первична, LLM — вторичен

## Статус
Принято

## Контекст
LLM — мощный инструмент, но он не должен определять архитектуру проекта.

## Решение
LLM используется только как инструмент анализа и генерации.
Книга — первичный источник знаний. LLM — инструмент работы с книгой.

Никакие архитектурные решения не принимаются на основе возможностей LLM.

## Последствия
- Архитектура не зависит от конкретной LLM-модели
- При смене провайдера меняется только адаптер
- Данные (json, sqlite) — главный актив проекта
- LLM не имеет доступа к внешнему миру без подтверждения автора
